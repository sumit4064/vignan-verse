A modern campus management platform built using React, Vite, and Firebase that centralizes essential student services like alumni, lost & found, clubs, events, departments, and library access with secure authentication and real-time data handling.

---

## 🔥 Features

* 🔐 Google Authentication (Firebase)
* 👨‍🎓 Student & Alumni Management
* 🔍 Lost & Found System
* 🏆 SAC Clubs & Department Information
* 🎉 Fest & Technical Events
* 📚 Digital Library Management
* 🌙 Dark/Light Theme UI
* ⚡ Fast performance with Vite
* 📱 Responsive modern UI

---

## 🛠️ Tech Stack

### Frontend

* React (Vite)

* Tailwind CSS

### Backend / Services

* Firebase Authentication

---

## ⚙️ How It Works

1. User logs in using Google authentication
2. Firebase verifies user and creates profile
3. Data is fetched from Firestore in real-time
4. Users interact with modules:

   * Students / Alumni
   * Lost & Found
   * Clubs / Events
5. Admin can manage and update data

---

## 🔐 Authentication & Security

* Firebase Google Sign-In
* Secure session handling
* Role-based access (Admin / Student)
* Firestore rules for data protection

## 🖥️ Run Locally

### **Prerequisites**

* Node.js installed

---

### 1️⃣ Install dependencies

```
npm install
```

---

### 2️⃣ Setup Environment Variables

Create a `.env.local` file:

```
GEMINI_API_KEY=your_api_key_here
```

---

### 3️⃣ Run the app

```
npm run dev
```

---

### 4️⃣ Open in browser

```
http://localhost:3000
```

---

## 🚀 Deployment

### Vercel / Firebase / Render

1. Push code to GitHub
2. Connect repository
3. Add environment variables
4. Deploy

⚠️ Add deployed domain in Firebase Authentication settings

---

## ⚠️ Notes

* Firebase requires authorized domains
* Do not expose `.env.local`
* Ensure Firestore rules are configured properly
* Google login requires popup enabled
